主幹式開發

Trunk-Based Development

多數提交進主幹，發布分支短命存在，降低長期分支合併的複雜度。

02

Pull Request

Pull Requests

協作審查程式碼變更，比較來源分支與目的分支後才合併。

🤖
03

Amazon CodeGuru Reviewer

Automated Code Review

機器學習驅動的程式碼審查，找出難以察覺的缺陷並提供修復建議。

🏗️
04

AWS CodeBuild

Fully-Managed Build

全託管建置服務，編譯程式碼、執行測試並產出軟體套件，隨用量擴展。

📄
05

buildspec.yml

Build Specification

定義 install/pre_build/build/post_build 等階段指令的 YAML 建置規格檔。

🗄️
06

建置快取

Dependency Caching

快取相依套件縮短建置時間，可用 S3 生命週期原則使快取到期失效。

🚀
07

AWS CodeDeploy

Automated Deployments

全託管部署服務，自動化將程式部署到 EC2、Fargate、Lambda 等平台，避免停機。

🪝
08

生命週期事件掛勾

Lifecycle Event Hooks

ApplicationStop → BeforeInstall → AfterInstall → ApplicationStart → ValidateService 的 AppSpec 掛勾順序。
