## 使用說明

- **檢視**：用瀏覽器開啟 `index.html`，或直接開啟任一 `Mx_*.html`。
- **列印／PDF**：瀏覽器列印（Cmd/Ctrl+P）即可存成 PDF，版面已為列印最佳化。
- **離線**：所有樣式與內容內嵌於單一 HTML，無需網路。
