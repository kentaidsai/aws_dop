01

IaC 是什麼

Infrastructure as Code

用程式碼（如 YAML/JSON）定義基礎設施，可版本控制、重複且可靠地建立。

🧾
02

範本結構

Template Anatomy

Parameters、Mappings、Conditions、Resources（必要）、Outputs 等區塊組成。

🧱
03

巢狀堆疊

Nested Stacks

用 AWS::CloudFormation::Stack 把共用元件拆成子範本，方便重用與維護。

Network / App 巢狀範本
🔀
04

變更集

Change Sets

預覽堆疊變更對現有資源的影響，確認後才真正套用到堆疊。

🕵️
05

偏移偵測

Drift Detection

比對堆疊實際設定與範本期望值，找出被手動修改的資源。

🧩
06

匯出/匯入

Export / ImportValue

用 Outputs Export 搭配 Fn::ImportValue 在堆疊間共享資源，無需硬編碼 ID。

🛡️
07

刪除策略

DeletionPolicy

Retain/Snapshot/Delete 控制刪除堆疊時資源的保留方式。

RDS DeletionPolicy: Snapshot
🧰
08

cfn 輔助腳本

cfn-init / cfn-signal

在 EC2 執行個體上安裝軟體，並用 cfn-signal 通知堆疊建立完成。
